## [1.0.0] - Initial Release
### Added
- Core gameplay: catch falling eggs with a basket
- Mouse controls (click and drag)
- Arrow key / A-D keyboard controls
- Score tracking system
- Best score recording
- Time challenge (1:45 time limit)
- Night mode toggle (N key)
- Pause feature (P / ESC)
- Menu system (Start, High Score, Help, Exit)
- Game states: Menu, Play, Pause, Game Over, High Score, Help
- 800x600 pixel game window
